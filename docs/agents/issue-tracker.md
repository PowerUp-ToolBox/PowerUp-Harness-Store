# Issue tracker

Issues live in GitHub Issues for `PowerUp-ToolBox/PowerUp-Harness-Store`, managed with the `gh` CLI.

- Specs: label `spec` + phase label (`P0`, `P0.5`, `P1`, `P2`) + milestone for the phase. Title format `[<SPEC-ID>] <title>`; SPEC-IDs encode build order within a phase.
- Blocking edges: native GitHub issue dependencies ("blocked by") where available, mirrored as a "Blocked by" section in the body.
- Triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` (default vocabulary).
- External PRs as a request surface: off.
